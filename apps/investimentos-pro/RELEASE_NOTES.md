# Investimentos Pro 4.0.25 — Windows x64

Simulador educacional desktop associado ao ecossistema BankCore.

## Destaques

- Chart Trading e menu contextual com acabamento translúcido e paleta BankCore.
- Boletas de compra e venda com preço e quantidade editáveis.
- Menu com exibir/ocultar Chart Trading, inserir indicador e tempo gráfico.
- Correções de contraste dos botões secundários nas configurações.
- Botão Sair no rodapé da barra lateral esquerda.
- Ajustes de enquadramento e separação das escalas dos indicadores.

## Requisitos

Windows 10/11 x64 e Microsoft Edge WebView2 Runtime. Dados locais em `%APPDATA%\com.investimentos.pro\`. Não há integração de contas ou saldos com o backend bancário BankCore.

## Validação

Build de produção concluído. Os 10 testes existentes passaram durante a implementação das boletas; não substituem uma validação visual completa. A alteração posterior do botão Sair teve build de produção concluído.
